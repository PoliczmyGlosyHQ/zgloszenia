# PoliczmyGlosy.pl

Znalazłeś błąd w [serwisie](https://policzmyglosy.pl/) albo masz pomysł na zmianę? Kliknij „New issue” i opisz, o co chodzi.

Podaj link do strony. Jeśli dane się nie zgadzają, dołącz źródło, z którym je porównujesz. Sprawdź też, czy ktoś już zgłosił ten problem.

Zgłoszenia są publiczne, więc nie wpisuj danych osobowych. W sprawach prywatności i bezpieczeństwa napisz na [kontakt@policzmyglosy.pl](mailto:kontakt@policzmyglosy.pl). Możesz też napisać, jeśli nie masz konta na GitHubie.

GitHub służy nam do obsługi zgłoszeń. Kod serwisu nie jest jeszcze publiczny.
